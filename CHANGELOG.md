# Изменения

## 1.2.0 — 25 сентября 2026

- Публичный самодостаточный `install.sh` для `bash <(curl -fsSL ...)`.
- Три вопроса ДО APT: SECRET_KEY, исходящий IPv4 панели, домен ноды.
- Удалены прежние IP-пресеты из кода, документации и тестов.
- Скрытый ввод через `/dev/tty`, поддержка длинных ключей и восстановление терминала после Ctrl+C.
- Передача данных в Python через stdin, не через argv или экспортируемые переменные.
- Повторный запуск читает сохранённые параметры; существующий node-only режим сохраняется.
- DNS проверяется перед записью новой конфигурации: ошибка домена не сохраняет неверные параметры.
- Тело установщика сначала полностью разбирается Bash; неполная загрузка внутри функции не запускает установку.
- Добавлены README, памятка публикации, правила Git/LF, ограниченный сканер секретов и CI без развёртывания.
- Сохранены обновления, очистка, IPv4-only, МСК, reboot понедельник 04:00, UFW, Fail2ban, Docker, Nginx/Certbot и локальный Selfsteal.

Основа — прежняя node-only версия. Права управления панелью не добавлены:
Node/Profile/Host/Squad по-прежнему не создаются и не редактируются этим скриптом.
