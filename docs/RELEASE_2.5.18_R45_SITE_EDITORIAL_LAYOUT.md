# Node Install 2.5.18 r45 — каталог сайтов: редактура и композиции

## Область изменений

Этот выпуск ограничен 120 статическими сайтами-прикрытиями, их генерацией, тестами и релизными инструкциями. Сам установщик, REALITY/Xray, Nginx, Docker, SSH, firewall, nftables, каскад и сетевые службы **не изменены**. Публикация сайта по-прежнему проходит через существующий staging-механизм с резервированием и откатом. Установленные ранее сайты **не заменяются автоматически**.

## Что было исправлено

- Для 96 каталожных публикаций (`13`–`108`) подготовлены **384 отдельных тематических редакционных заметки** в `scripts/site_editorial.py`, строго по четырём материалам каждой темы. Никаких имён вымышленных покупателей, адресов компании, обзоров клиентов, измеренных результатов или контактов не добавлено.
- Страница материалов содержит по три текстовых абзаца на тему; ссылки карточек на главной переходят к отдельным якорям `journal.html#story-1`…`story-4`. Это работает без JavaScript.
- Существующие 16 стилистических семейств дополнены **шестью композициями** (`index`, `folio`, `cover`, `ledger`, `studio`, `archive`), выбираемыми детерминированно по теме. Их мобильные варианты не используют горизонтальную прокрутку.
- Для 96 каталожных тем скорректирована светлая акцентная палитра: расчётная контрастность текста/фона акцента по WCAG AA не ниже 4.5:1. Это относится к цветовой паре акцент/фон сайта, а не служит полной сертификацией доступности.
- Оставлены без структурной переработки 12 исходных и 12 signature-темы, сохраняются их индивидуальные особенности. Из публичных футеров и небольших декоративных подпунктов убран застывающий год 2026.
- Сохранены исходные URL и файлы: `index.html`, `journal.html`, `about.html`, `questions.html`, `404.html`, `style.css`, `favicon.svg`, `robots.txt`, `sitemap.xml`. Все ресурсы локальные, без внешних шрифтов, скриптов, форм, трекеров или внешних изображений.

## Проверки

- `python3 scripts/site_audit.py --rich`: 120 тем, 600 HTML-страниц, 1 080 файлов (PASS).
- `python3 scripts/build_site_gallery.py --check`: 120 ссылок (PASS).
- `python3 -m unittest discover -s tests -p test_r45_site_editorial_layout.py -v`: проверка 384 заметок, связности ссылок, доменных метаданных и соответствия готовых статических файлов генераторам.
- Chromium через `scripts/site_visual_review.py`: 120 главных страниц × 2 viewport (1280×800 и 390×844), всего 240 проверок. JSON и контакт-листы в `preview/site-gallery/*-r45.*`; ссылки галереи также ведут на актуальные снимки r45 (исторические r23 сохранены). Числа **не** доказывают качество дизайна: дополнительно нужен ручной просмотр и проверка в реальном HTTPS-окружении.
- Статические `cover-variants/*/style.css` остаются **исходными базовыми файлами**. Генератор добавляет доменную палитру поверх них при рендере; сохранение готового CSS вместо базы приводит к повторному добавлению палитры. Тест r45 контролирует эту особенность.

## Сайты и домен

`site-catalog/*/sitemap.xml` в архиве содержит *только предварительный домен* `preview.example.test`. Это не production-адрес. При штатной публикации через генератор создаётся новый sitemap/robots.txt по фактическому подтверждённому домену. **Не копируйте статическую папку `site-catalog` на VPS напрямую** вместо существующего механизма деплоя.

## Проверка и откат на staging

1. Сделать snapshot VPS и убедиться в доступности аварийной консоли провайдера.
2. На отдельной staging-ноде с рабочим HTTPS установить выбранную тему штатным `site-install` или использовать `site-preview` для локальной предварительной проверки. Не заменять вручную конфигурацию Nginx.
3. Проверить домен, сертификат, навигацию, запросы `GET /`, `GET /journal.html`, `GET /404.html` (с ожидаемым HTTP 404 для несуществующих путей), мобильное отображение и отсутствие запросов к третьим сторонам.
4. При ошибке публикации воспользоваться существующим `site-rollback`, который восстанавливает сохранённые файлы. **Не менять Xray для отката сайтов.** Если сломан доступ к VPS или сервисы ОС, восстановить snapshot провайдера.

## Границы гарантий

Сайт не маскирует IP VPS и не гарантирует скрытность от DPI/ТСПУ. Изменения относятся к правдоподобности и качеству публичного HTML/HTTPS-контента при обычном посещении. Не проводились живые проверки TLS/REALITY, Nginx на VPS, DNS/IPv6/UDP, Remnawave, Android/iOS и эффективность против сетевых фильтров. Релиз остаётся `INCOMPLETE_STAGING_ONLY`.
