# Одностраничник Selfsteal — 2.1.1

## Что это

Статическая страница «Сайт в разработке» на вашем домене. Тёмная палитра, крупная типографика, графический объект на CSS, адаптация к телефону и компьютеру. Подпись берётся из домена; дополнительный вопрос при установке не нужен. Цветовой акцент и угол декоративного кольца детерминированы доменом; это дизайн, **не доказательство устойчивости к обнаружению**.

В странице нет JavaScript, внешних шрифтов/картинок/CDN, аналитики, cookie, формы сбора email, фиктивного личного кабинета, рекламных обещаний или упоминаний VPN. Пример вместе с CSS и SVG favicon занимает **7668 байт** до HTTP/TLS-заголовков. Размер немного зависит от домена. Реальный браузер использует системные шрифты; на разных ОС их вид может отличаться.

Никаких новых портов, контейнеров, CMS, backend или базы данных. Nginx остаётся на хосте и отдаёт файлы через существующий Selfsteal socket. TCP/443 принадлежит Xray. Транспорт остаётся VLESS RAW REALITY.

## Новая VPS

При новой установке 2.1.1 страница создаётся автоматически после трёх значений. Существующий index другого содержимого не заменяется обычной установкой. Пример для просмотра находится в `preview/index.html`; установщик не зависит от этой папки — HTML/CSS/SVG встроены в `install.sh`.

## Уже работающая 2.0.3

**Полный install повторно не выполняйте ради сайта.** После snapshot и проверки скачанного файла используется отдельный флаг нового установщика:

```bash
sudo bash install.sh --update-cover
```

Этот режим допускает только завершённую принадлежащую проекту 2.0.3, 2.1.0 или 2.1.1. Он не меняет install-version, SSH/UFW, параметры ядра, время, Nginx-конфиг, image digest, профиль, REALITY-ключи или файлы секретов. APT, Docker Compose и команды перезапуска/перезагрузки в этом режиме не вызываются. **Исправления системной части 2.1.0/2.1.1 этим не устанавливаются.**

Порядок:

```text
installer lock
   → проверка прав, версии, INSTALL_COMPLETE и незавершённых транзакций
   → nginx -t + Selfsteal + локальный HTTPS :443 с ожидаемым index
   → backup прежнего index + SHA256 + повторное чтение backup
   → persisted cover-pending
   → публикация новых CSS/SVG под именами, зависящими от хеша
   → одна атомарная замена index.html
   → повторная проверка Nginx/Selfsteal/локального :443
   → receipt active + указатель backup
```

Старые assets не удаляются. Это исключает промежуточный index, ссылающийся на ещё не созданный CSS, и позволяет вернуть прежнюю страницу. Повторное обновление одинаковой страницы — no-op с проверкой assets; повреждённый CSS не считается успешным повтором.

Проверки HTTPS здесь **локальные**. После применения откройте свой домен обычным браузером извне и повторно проверьте VPN-клиентом. Команда не доказывает доступность из каждой страны и не проверяет admin API панели.

## Backup / rollback

Копия находится в `/var/lib/vkarmani-node/backups/cover-.../`: `index.before` и `receipt.json`, файлы `0600`, каталог `0700`. Указатели: `cover-last-update`, при незавершённой операции — `cover-pending`.

```bash
sudo bash install.sh --rollback-cover
```

Откат проверяет указатель, расположение и SHA256 копии, соответствие домену и текущий index. Позднее самостоятельное изменение страницы не перетирается. Возвращается только index; старые assets уже сохранены. Проверки после отката выполняются снова, без перезапуска VPN или Nginx.

При обычной ошибке или обрабатываемом сигнале после публикации выполняется попытка автоматического возврата index. **SIGKILL, отключение питания, сломанная файловая система и исчерпание диска могут помешать откату.** `cover-pending` позволяет начать явное восстановление, но не заменяет snapshot. При `COVER_ROLLBACK=INCOMPLETE` сначала проверить диск, права, backup и состояние страницы; не удалять pending вслепую.

Откат сайта **не является** откатом установки, Docker-образа, ОС или клиентских сессий. Многократные разные обновления оставляют assets и backups; автоматическое удаление не добавлено, чтобы не разрушить возврат.

## Проверки

Изолированные тесты: idempotence, права, symlinks, повреждённый backup, path traversal, чужая версия, незавершённая транзакция, ENOSPC до публикации, EIO после rename, сигнал, отказ health check и запрет перезаписи последующего изменения оператора. Отдельно настоящий Nginx отдаёт новый HTML, CSS и SVG по TLS 1.3 + PROXY protocol; HTTP/1.1 и HTTP/2 проверены.

В Chromium проверены 9 ширин 320–1920 px, отсутствие горизонтального overflow и наложения заголовка/текста. В среде браузеру запрещена навигация по HTTP/file URLs, поэтому для **визуального** теста HTML и идентичный CSS переданы в память через Playwright, не через сеть. Реальная выдача файлов проверена отдельно Nginx. Safari/Firefox и физические телефоны не тестировались.

Абсолютного отсутствия риска нет. Общий публичный шаблон, домен и адрес сервера остаются наблюдаемыми; новая страница не объявляется гарантией неотличимости от любого обычного HTTPS-сайта.
