# Визитка Selfsteal — 2.2.0

## Состав

Лёгкая нейтральная страница «Сайт в разработке», встроенная в сам `install.sh`. Четыре варианта: `orbit` (тёмные кольца), `fold` (светлая бумажная геометрия), `grid` (синяя сетка), `horizon` (фиолетовые арки). Различаются композиция, цветовой акцент, фон, типографика и headline. Подпись формируется из домена ноды, без дополнительного вопроса установки.

Нет JS, внешних шрифтов, картинки/CDN, cookies, аналитики, форм, личного кабинета, выдуманной компании или рекламы VPN. Страница остаётся статической — никакого backend, контейнера или таймера ротации. Системные шрифты на разных ОС могут отличаться.

При первом разрешённом install/update генерируется seed (32 случайных байта в hex) и сохраняется в root-only `cover-identity.json`. Из domain+seed выбираются вариант и связанные параметры; ответ не рандомизируется на каждый запрос, перезапуск, проверку или обновление одного release. Многократный рендер даёт те же байты. Это воспроизводимый внешний вид, не доказательство анти-DPI-стойкости. Старый seed не трогает и не заменяет REALITY keys.

## Размеры и preview

Для `node.example.com` четыре HTML+CSS+SVG-набора занимают 7833–8999 байт, без HTTP/TLS-заголовков и отдельно обслуживаемых robots/404/fallback favicon. На других доменах размер меняется. Контентные имена CSS/SVG включают первые20hex SHA256; Nginx использует Cache-Control max-age604800 и ETag, HTML требует revalidation (`no-cache`). Зависимостей сайта от внешнего Интернета нет.

[Галерея](../preview/gallery.html) и [описание preview](../preview/README.md) доступны в архиве. `preview/index.html` — один контрольный вариант, `preview/variants/*/index.html` — все четыре. Seed в preview — только тестовый, не состояние настоящей установки. Браузерные снимки — Chromium144, 390px и1440px. Проверены36 сочетаний (4×9 ширин320–1920px), отсутствие горизонтального overflow, перекрытия заголовка/описания, внешних запросов, JS и ошибок, focus и reduced-motion. Это не полный WCAG-аудит и не сквозной browser→REALITY тест.

## Новая установка

При новой2.2.0 сайт создаётся автоматически. Чужой index не заменяется обычным install. HTML публикуется атомарно после локальных versioned assets. Seed создаётся атомарно без перезаписи одновременно появившегося файла. Повреждение, неправильные права, symlink/FIFO/дубликаты JSON и чужой domain вызывают отказ вместо скрытого сброса.

`favicon.svg`, `robots.txt`, `404.html` создаются при первой установке. Режим site-only update намеренно не перетирает существующие копии, чтобы не портить уже работающий сайт/откат. Новая allowlist Nginx допускает только index, эти служебные файлы и хешированные CSS/SVG; произвольные новые файлы сами по себе не публикуются.

## Работающая нода

После backup и проверки доверенного нового файла можно отдельно выбрать:

```bash
sudo bash install.sh --update-cover
```

Допускаются рассмотренные завершённые owned2.0.3,2.1.0,2.1.1,2.1.2,2.1.3,2.2.0. До изменения проверяются marker/locks, config, Nginx/socket и локальный проход через443. Создаётся backup прежнегоindex и receipt с SHA; изменённый вручную index не перетирается при rollback. Assets старой страницы сохраняются. После публикации — повторная проверка; при отказе предусмотрено восстановление index. Незавершённая транзакция отмечается pending и не маскируется новым PASS.

**Это обновляет только сайт и state его транзакции, не host Nginx, checker, firewall, Docker, certs, keys, профиль панели или install-version.** Рестартов сервисов ради статики нет. Сохраняемый seed после неудачи/отката — намеренная часть воспроизводимости; текущий внешнийindex может быть старым, seed относится к новому оформлению для следующего разрешённого update.

Откат только при необходимости, а не следом за успешным обновлением:

```bash
sudo bash install.sh --rollback-cover
```

Внезапное выключение, SIGKILL или отказ ФС не покрываются обещанием «откат гарантирован всегда». Не удалять pending/receipt/backup вручную. Полное описание — [OPERATIONS](OPERATIONS.md). Новые зависимости не ставятся. НаличиеGoogle/чужого target в панели site-onlyupdate не исправляет.
