# 🧪 Проверки Node_Install 2.1.0 / ci-fix1

Дата: **30 сентября 2026**. Это отчёт исправления CI; версия production-скрипта остаётся 2.1.0. `install.sh` не изменён, SHA256 `9420c5a76749fd0ae52c26279e78069fca42b40d8a7bae9d80b950a89b3f976c`.

## Воспроизведение до изменения

| Опыт | Наблюдение |
|---|---|
| Полный исходный набор от root | 349 тестов, 17.955 с, OK, 0 skips |
| Полный исходный набор от UID 65534 | 349 тестов, 18.487 с; unittest сообщил 1 failure в `test_real_apt_locked_cache_defers_then_cleans` |

| Настоящий APT с исходным перенаправлением одного archives | После очистки тестового `.deb` пытается открыть системный `/var/lib/apt/lists/lock`; `rc=100`, Permission denied |
| Настоящий Git в временном каталоге без `.git` | `git diff --check`: `rc=129`, Not a git repository |

[Лог исходного non-root набора](evidence/ci_original_unprivileged.txt), [прямое воспроизведение APT](evidence/ci_apt_reproduction.txt). Повторение полного набора в одной ранней объединённой инструментальной команде получило внешний timeout после записи итоговой сводки; оно не засчитано как завершённый успешный запуск. Отдельный последующий запуск исходной APT-группы подтвердил код 1 без внешнего timeout.

[Лог non-root](evidence/ci_fixed_unprivileged.txt), [лог root](evidence/ci_fixed_root.txt).

Семь новых регрессий: два настоящих APT-теста фактических разрешённых путей и сохранности соседних данных; пять проверок порядка Git bootstrap/checkout, матрицы ОС, раздельных шагов и проверок manifest, отсутствия подавления ошибок/повышения прав тестов, полного набора приватных temp paths Nginx.

Изоляция настоящего APT-теста исправлена, а не имитирована: используются настоящие `apt-get`, `apt-config` и POSIX lock. Вход в production-функции установщика не выполняется. Существующие протокольные, fault-injection и TLS-тесты сохранены. Тесты Docker/системных служб остаются имитациями; Nginx и локальные TLS-сессии — настоящие.

В root-прогоне не изменились наблюдавшиеся метаданные системных путей APT, Nginx и dpkg-status. [Список наблюдаемых путей](evidence/ci_host_paths_preserved.json). Это не всеобщий syscall-аудит, но воспроизведённый выход APT за пределы fixture больше не нужен для успешного теста.

## Среда и точность утверждений

Локальный контейнер **Debian 13, x86_64**, Python 3.13.5, cryptography 46.0.4, PyYAML 6.0.3, Bash 5.2, Nginx 1.26.3, OpenSSL 3.5.5, APT 3.0.3. Локальная среда не равна Ubuntu 22.04/24.04/26.04 и GitHub-hosted runner.

Публичная сводка Actions #36677103684 прочитана: коды 1/1/129. Полные удалённые логи и побайтовая копия удалённого commit не получены. Ошибка изоляции APT воспроизведена в выданном архиве; сценарий отсутствия Git до checkout согласуется с 129, но полный лог нужен для строгой привязки удалённой причины. Новый workflow не запущен на GitHub и не называется успешным до нового push/run.

**Не выполнены:** новые VPS-install/reboot, реальные SSH/UFW/Fail2ban/GRUB/Docker/Xray/ACME/NTP, Ubuntu-гости и Python 3.10/3.12/3.14, arm64, клиентский VPN и нагрузка. Рабочая нода пользователя не менялась. Браузерный тест не перезапускался: HTML/CSS/SVG не менялись. Старые результаты не переназваны в новые измерения.

## Поставка

При подготовке отдельно проверяются YAML workflow и Bash-синтаксис его run-блоков, compile всех Python-файлов тестов, контрольные суммы, наличие всех исходных файлов, идентичность production-скрипта и preview, отсутствие `.git` в архиве и CRC ZIP. Локальный Git clone применяется для проверки checkout → manifest → тесты → неизменность tracked files; эта проверка не запускает GitHub Actions и не обращается к VPS. Окончательные результаты проверки уже распакованного ZIP записываются во внешний `Node_Install_2.1.0_ci_fix1_RELEASE_VALIDATION.json`, чтобы не менять содержимое запечатанного архива.

Предыдущие [README](history/README_2.1.0.md), [TEST_REPORT](history/TEST_REPORT_2.1.0.md) и [RELEASE_VALIDATION](history/RELEASE_VALIDATION_2.1.0.json) 2.1.0 сохранены дословно. Их прежнее описание изоляции APT было недостаточным: новый регрессионный опыт и исправление задокументированы здесь и в [CI_FIX_2.1.0](CI_FIX_2.1.0.md).


Запускать в отдельной Linux dev/CI-среде с тестовыми зависимостями, не устанавливая их на рабочую VPN-ноду ради этого исправления. GitHub матрица сохранена; новый удалённый run должен подтвердить все три задания.
