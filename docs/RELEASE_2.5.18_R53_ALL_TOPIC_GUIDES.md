# r53: предметные руководства для оставшихся 64 сайтов

Статус: `INCOMPLETE_STAGING_ONLY`. Сборка не устанавливалась на VPS и не проверялась как реальный сетевой сервис.

## Изменения

- Для всех 64 недоработанных тем каталога подготовлены индивидуальные вводные материалы, три шага, три контрольных пункта и ограничения. Новые тексты размещены в `scripts/site_workbooks_r53.py` и подключены через существующий рендерер `site_workbooks.py`.
- Сохранены девять файлов каждого сайта, прежние адреса страниц, CSS, локальные ресурсы, CSP и схема публикации; новых зависимостей и внешних запросов нет.
- У 16 тем остаются углублённые материалы r51, у 40 — практикумы r52, у остальных 64 — новая предметная секция r53. Теперь у 120/120 тем есть хотя бы один выделенный подробный материал. **Это не означает, что все сайты полноценно наполнены и визуально независимы**: многие основные страницы и четыре короткие статьи требуют отдельной содержательной редакторской работы.
- Отчёт `scripts/site_quality_review.py` продолжает требовать независимую редактуру всех 120 сайтов; старые раздельные счётчики r51/r52 не смешиваются с r53.
- Реальная работа VPN и незаметность для сетевой фильтрации не измерялись; установки, SSH, файрвол, сетевые транспорты и конфигурация Nginx не изменялись.

## Проверки перед публикацией

Из чисто распакованного ZIP: `sha256sum --check SHA256SUMS`, `python3 scripts/verify_release.py --root .`, `bash -n install.sh`, `python3 -m compileall -q scripts tests integrations`, `python3 scripts/site_audit.py --rich`, `PYTHONPATH=$PWD:$PWD/tests python3 -m unittest discover -s tests -v`. На staging VPS отдельно проверить HTTP-статусы, TLS, заголовки, пути, 404 и rollback, не затрагивая production.
