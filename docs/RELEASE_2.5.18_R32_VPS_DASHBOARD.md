## Первое меню «Проверка VPS»

После Enter начинается щадящая диагностика с обновлением прогресса. По завершении результаты разделены на девять русских страниц:

1. Обзор и краткая расшифровка цветов.
2. Сервер: ОС, версия ядра, CPU, логические потоки, память, swap, свободное место, uptime, TCP congestion, службы.
3. IP / ASN: три независимых **приблизительных** GeoIP-провайдера (`ipapi.co`, `ipinfo.io`, `ipwho.is`), расхождения стран и IP, подтверждённые владельцы AS, без выдуманного риска.
4. Сервисы: TLS/HTTPS к 30 публичным сайтам и API (включая Google, YouTube, ChatGPT, DeepSeek, GitHub, Netflix, Spotify, Discord, TikTok). Без авторизации и автоматических редиректов.
5. DNS (IPv4 A) и локально замеченная Cloudflare CDN-точка.
6. ICMP ping, потери, HTTPS p50/p95/jitter, маршрут traceroute (если программа установлена).
7. Скорость до своего iperf3 endpoint — **не запускается автоматически**.
8. CPU / RAM / диск — **не запускается автоматически**.
9. Пояснения, ограничения методики и безопасность данных.

Управление: **↑↓, PgUp/PgDn, Home/End, колесо мыши** (зависит от мышиного протокола терминала), цифры **1–9** — разделы, **0** — все разделы, **Tab** — следующий, **E** — экспорт, **S** — iperf3, **B** — тест CPU/RAM/диска, **Esc** — возврат назад. Размер шрифта и передача событий мыши определяются SSH-клиентом (MobaXterm), а не кодом Python. В `TERM=dumb` доступен обычный текст без графического экранного браузера.

## Экспорт

По **E** выбираются TXT, JSON, PNG или все три. Файлы создаются только после явного выбора в `root:0700` каталоге `/root/NodeInstall-Reports` (для обычного пользователя — приватная директория в HOME). Права `0600`, уникальные имена, запись с `O_EXCL` и `O_NOFOLLOW`, `fsync`. Внутри отчёта — публичные IP, ASN, версия ОС, маршруты, результаты сервисов. Перед размещением публично отчёт необходимо проверить на раскрытие личной информации и инфраструктуры. Ключи REALITY, пароли и токены не запрашиваются, не добавляются и не экспортируются.

PNG создаётся с русскими цветными заголовками, чередованием строк и таблицами. При наличии уже установленного Pillow + системного кириллического шрифта доступен улучшенный вид; при отсутствии — реализован резервный PNG-рендерер **только на Python stdlib**, без дополнительных пакетов. Длинные PNG ограничены по объёму; полный текст сохраняется в TXT/JSON.

## Что не следует трактовать как доказательство

- `HTTP 200` подтверждает ответ, но не доступность аккаунта/подписки/YouTube Premium/VPN-клиента.
- `HTTP 401` — требуется авторизация; `403`/`451` — блокировка, WAF, anti-bot, регион или другое ограничение **неотличимы одним запросом**. `Timeout` не доказывает блокировку.
- GeoIP по 3 справочникам расходится и бывает неточен; нельзя считать это точным физическим расположением, юридической регистрацией, детектором proxy/VPN/Tor, fraud score либо доказательством «чистоты IP».
- HTTPS latency не равна ICMP RTT. ICMP звёздочки в traceroute не означают потери конечного TCP/HTTPS соединения.
- Тест iperf3 запускается только по **S** с явно указанным собственным публичным IPv4; до публичных случайных iperf3 endpoint нет автоматических тестов.
- Тест **B** — быстрый Python microbenchmark, CPU ~0.6 с, копирование 8 MiB и создание/`fsync`/удаление временного файла 8 MiB в `/tmp`. Это не fio/YABS/sysbench и не нагрузочная приёмка.
- Внешние GeoIP-провайдеры и публичные сайты узнают исходящий IP VPS. Отсутствующие API/сеть выводятся как ошибки или «не проверено», а не подставляются данные из образцов.

## Диагностика без интерфейса

```bash
python3 -I integrations/vps_dashboard.py full
```

Этот вызов выводит **JSON Lines**, включая этапы `progress` и один `result`. CLI не сохраняет файлы автоматически. Для удобного просмотра и сохранения используйте интерактивное `bash install.sh --menu` и пункт «Проверка VPS».
