# Node Install 2.5.18 r29 — SSH TUI / единая проверка VPS / безопасный повторный вход

Статус: **INCOMPLETE_STAGING_ONLY**. r29 не автоматически разворачивается на VPS и не является подтверждённым production-релизом.

## Устранённые UX дефекты r27/r28

1. Мерцание: старый `Terminal.logs()` стирал экран каждый тик (0.12 с) даже без новых данных, а `Terminal.paint()` делал промежуточный refresh. Исправлено через `noutrefresh()/doupdate()` и редкие обновления по событиям.
2. Визуал: рамка, центрированный бренд, контрастные зелёные оттенки, выбранная строка с фоновой подсветкой. Ограничение: точные веб-шрифты/пиксели невозможны в ANSI/SSH; шрифт задаётся в MobaXterm. Стандартный безопасный fallback для малых/нецветных терминалов.
3. Повторная команда GitHub: существующий checkout проверяется, не стирается; bootstrap изолирован внутри дочернего `bash`. Если проверка SHA или версии остановилась, **SSH не закрывается**.
4. VPS: одно действие, единый read-only отчёт. Прямые HTTPS-запросы, ICMP/маршрут и CDN могут иметь ограничения; 401/403 сами по себе не означают блокировку. Скорость — только свой публичный iperf3, ввод необязателен. При отсутствии утилиты не происходит её установки.

## Поведение после сбоя установки

Команда `bash install.sh --menu` открывает меню **даже при наличии checkpoint**, но мастер новой установки не обходит защиту `owned-installation`. При незавершённом состоянии разрешены только диагностика, план восстановления и строго проверенное ручное завершение финальной фазы (`--finish-install`). Не удаляйте маркеры/логи/резервные копии и не пытайтесь автоматом переустановить ноду поверх частично изменённой ОС. Восстановление других фаз требует проверенного снимка VPS и консоли провайдера.

## Безопасные действия

```
cd /root/Node_Install-2.5.18
bash ./install.sh --menu
bash ./install.sh --vps-check --format table full
```

Опциональный измеритель TCP скорости:

```
bash ./install.sh --vps-check --format table full --speed-server ВАШ_PUBLIC_IPV4
```

В последнем примере замените `ВАШ_PUBLIC_IPV4` на публичный адрес принадлежащего вам тестового сервера с запущенным `iperf3 -s` (не запускайте тест против чужого сервера).

## Область изменений и rollback

Изменены только локальный терминальный UI, агрегирование read-only сетевых проверок, README/CHANGELOG/тесты/манифест. Рабочие systemd, UFW, SSH, Docker, профили Xray, сертификаты и default IPv4 policy не затронуты. Откат на уровне проекта — вернуть предыдущий исходный ZIP; **не** перекатывайте его поверх уже установленного сервера без анализа installed version/checkpoint. Полный откат состояния VPS — из проверенного snapshot провайдера.

Непроверенное: интерактивная установка на реальной новой VPS, доступность конкретных сервисов и реальные скорости из сетей клиента, внешний GitHub Actions CI для этого непромотированного ZIP.
