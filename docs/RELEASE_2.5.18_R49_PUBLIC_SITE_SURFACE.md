# Node Install 2.5.18 r49 — публичный состав сайтов и удобство чтения

**Дата:** 2026-11-07. **Основа:** полный архив r48. **Статус:** `INCOMPLETE_STAGING_ONLY`.

## Цель и границы

Устранить служебные текстовые маркеры из **публичных HTML/CSS/SVG/robots/sitemap**, проверить эту гарантию перед каждой публикацией и улучшить обычные сценарии чтения. Внутренние README, диагностические инструменты и технические комментарии в Python/Nginx намеренно не удаляются: они не публикуются как сайт, а нужны администраторам и для восстановления. На VPN-транспорт и реальные сетевые отпечатки эта работа не влияет.

## Что сделано

1. В генераторах 96 каталожных, 12 индивидуальных и 12 классических многостраничных сайтов убраны публичные CSS-комментарии, описывавшие кодогенерацию и имя темы. Для этих 120 пакетов CSS не содержит комментариев; HTML/XML/SVG не содержат HTML-комментариев.
2. В `scripts/site_audit.py` добавлена строгая проверка **каждого публикуемого файла** на технические метки (VPN/VLESS/Xray/REALITY/Remnawave, ASN, DPI/ТСПУ/РКН, внутреннее имя проекта и др.) и служебные комментарии. Нарушение останавливает развёртывание **до изменения файлов**, потому что `NodeWeb.site_install` уже вызывает `audit_bundle` перед записью. Запрещены внешние скрипты/формы/ресурсы по прежним правилам.
3. У 96 тематических статей появились рабочие ссылки «К содержанию» / «Back to contents» на локальный якорь и визуальная подсветка статьи по фрагменту URL (`:target`), без JavaScript.
4. У всех 120 тематических многостраничных комплектов появились стили для печати: скрываются меню и декоративные блоки, печатается основной текст. У 96 тем дополнительно предусмотрен `prefers-reduced-motion`; у 12 индивидуальных он уже был. Не добавлены внешние зависимости, трекеры, формы, cookies или личные кабинеты.
5. Статические снимки 108 сайтов `site-catalog` перегенерированы из соответствующих генераторов. Никакие URL, названия, тематики, файлы ресурсов и маршруты не удалены.
6. Новые негативные тесты проверяют запреты технических строк/комментариев и соответствие исходных сайтов генераторам, а также native-якоря и печать. Текущие Nginx `server_tokens off`, ограничение путей и механизм отката сохранены без изменений.

## Чего нельзя достичь HTML/CSS

- **ASN** принадлежит сетевому маршруту адреса VPS, а не исходнику сайта. Любой внешний наблюдатель может определить сеть/хостинг по публичному IP. Даже без слов `ASN` в HTML это не скрывается.
- Транспорт TLS/REALITY, IP/SNI, пакеты и поведение клиента не превращаются в обычный веб-трафик из-за замены CSS. Эта сборка **не** заявляет эффективность против ТСПУ или РКН.
- `server_tokens off` убирает версию Nginx, но может остаться само имя сервера; надёжность определяется обновлениями и отсутствием дефектов, не одним скрытым заголовком.
- Промежуточные локальные HTML в архиве содержат `preview.example.test` в canonical и sitemap для автономного предпросмотра; **штатный деплой заново генерирует файлы из актуального домена**, а `site_audit.py` проверяет соответствие домена. Не копируйте эти предпросмотры в webroot вручную.

## Безопасность и проверка

- Изменены только генераторы и аудит сайтов, отрендеренные статические снимки, документация, версия сборки и тесты. `install.sh`, приватные файлы/ключи, Docker, Xray/RemnaNode, Nginx, nftables, DNS, UFW, SSH и серверные настройки остались прежними.
- Перед внедрением: проверка ZIP/SHA256, snapshot VPS, консоль хостера, полный тест на staging. Смена сайта — через `scripts/site_manager.py`, а не повторная первичная установка.
- Проверки после публикации: доменные `canonical`/sitemap, 200 на 4 страницы, собственная 404 с HTTP 404, favicon, CSS, сертификат HTTPS, `nginx -t`, существующие VPN-клиенты. Проверки страниц не подтверждают устойчивость к фильтрации сети.
- Откат: штатная транзакция `site-rollback` через `site_manager.py`, либо проверенный snapshot. Любая ошибка проверки или незнакомое окружение — отказ без продолжения.
