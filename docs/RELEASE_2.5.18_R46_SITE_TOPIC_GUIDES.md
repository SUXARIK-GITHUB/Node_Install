# Node Install 2.5.18 r46 — предметный контент и доступность сайтов

## Область работ

Только локальный каталог 120 статических сайтов, редакционные тексты, генераторы, проверка HTML, галерея и тесты. `install.sh`, серверные интеграции, Xray, REALITY, Remnawave, Nginx, Docker, firewall, nftables, CI и схема каскада **не менялись**. Существующие VPS и опубликованные сайты не изменяются сами при распаковке архива.

## Изменения

1. `scripts/site_field_guides.py`: 384 отдельных пояснения (четыре для каждой из 96 тем) с предметными примерами и ограничениями. Они заменяют общие повторяющиеся средние абзацы журнала. Сохранены оригинальные 384 вводные заметки в `scripts/site_editorial.py` и локальные якоря `journal.html#story-1` ... `#story-4`.
2. Для 12 визуально самостоятельных тем добавлены 48 предметных пояснений к статьям, без изменения основного оформления и публичных маршрутов.
3. `scripts/site_catalog.py` и `scripts/signature_sites.py` исправляют надпись перехода к основному содержимому (`Skip to main content` / `К основному содержимому`), прежде ошибочно использовавшую подпись другой ссылки.
4. `scripts/site_audit.py` дополнительно проверяет целостность skip-link там, где есть основной якорь `#main`, и допустимость языка страницы. 12 исходных исторических тем без якоря `#main` оставлены неизменными.
5. Дополнены тесты для 384 уникальных текстов, 48 signature-заметок, локализации, текстовой длины, соответствия генерируемых страниц сохранённым статическим файлам, CSP, ссылок и полного набора 9 файлов каждой темы.
6. Локальная галерея дополнена обзором реальных журнальных страниц Chromium: `visual-review-journal-r46.json`, `visual-review-journal-desktop-r46.jpg`, `visual-review-journal-mobile-r46.jpg`. Скриншоты сделаны из изолированного HTML с локально встроенным CSS; исходный CSP файлов и сервер не изменялись.

## Безопасность, публикация, откат

- Не добавлены внешние ресурсы, JavaScript, шрифты, формы, API, трекеры, аккаунты или реквизиты вымышленных компаний.
- Не менялись пути сайтов: `index.html`, `journal.html`, `about.html`, `questions.html`, `404.html`, `style.css`, `favicon.svg`, `robots.txt`, `sitemap.xml`.
- `site-catalog/*/sitemap.xml` содержит только preview-домен. Публиковать через существующий `site-install`, который подставляет подтверждённый домен и выполняет проверку/резервирование/откат. Нельзя копировать preview-папки на production вручную.
- Перед проверкой на отдельной VPS: snapshot, проверка консоли хостинга, HTTPS, реальные запросы страниц и 404, затем `site-rollback` при дефекте сайта. Система ОС возвращается через snapshot в тяжёлых случаях.

## Проверки перед релизом

```
python3 scripts/site_audit.py --rich
python3 scripts/build_site_gallery.py --check
python3 -m unittest discover -s tests -p 'test_r46_site_content_quality.py' -v
python3 -m unittest discover -s tests -p 'test_r45_site_editorial_layout.py' -v
python3 scripts/verify_release.py --root .
```

Визуальная проверка на Chromium не заменяет реальный HTTPS и работу Nginx, а текстовый аудит — редактуру специалистом по каждой дисциплине. Защищённость от активного DPI сканирования и устойчивость к ТСПУ не доказываются наличием сайта. Статус релиза `INCOMPLETE_STAGING_ONLY`.
