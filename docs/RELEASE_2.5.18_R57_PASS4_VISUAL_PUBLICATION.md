# Node Install 2.5.18 — r57 / Этап 4: визуальное оформление и офлайн-контроль публикации

**Дата:** 12.11.2026. **Статус:** `INCOMPLETE_STAGING_ONLY`. **База:** `20261112-r56-site-content-pass3b-staging`.

## Область изменений

1. Для 96 тематических каталогов общего семейства добавлены предметные контурные SVG (68 типов пиктограмм), 11 направлений типографики и фрейм-оформления, вариации композиции hero; финальное сочетание графики, тематики и подписи уникально для каждой темы. Это не утверждение, что все 96 имеют независимый дизайн с нуля.
2. В SVG сохранены доступные русские/английские подписи (`aria-label`); видимые служебные порядковые номера тем удалены. Оригинальные 12 `cover-variants/` и 12 signature-дизайнов **не переписывались**. Существующие 120 тематик, имена файлов, маршруты, sitemap, robots, 404, CSP, локальные ресурсы и семантические тексты сохраняются.
3. `scripts/site_catalog.py` создаёт новую предметную иллюстрацию и CSS из `scripts/site_art_direction.py`. Статические файлы `site-catalog/` пересобраны; итоговый домен `preview.example.test` совпадает с генератором побайтово.
4. `scripts/site_visual_review.py` поддерживает четыре размера экрана (1280×800, 768×1024, 390×844, 320×720), четыре раздела (главная, материалы, о проекте, FAQ), контролирует horizontal overflow и обрезание текстовых блоков; просмотр выполняется из памяти локальным Chromium, не требует внешней сети и не отключает CSP опубликованного сайта. Chromium — **только дополнительный QA-инструмент**, не runtime-зависимость установщика.
5. `scripts/site_publication_review.py` выполняет read-only проверку все 120 комплектов с тестами ссылок, CSP, ресурсами, исходными статическими копиями. Применение Nginx-конфигураций/загрузка на сервер не выполняются.
6. `tests/test_r57_site_visual_publication.py` закрепляет базовые регрессионные проверки. В `preview/site-gallery/` сохранены обзорные снимки и JSON на четырёх размерах экрана; **галерея не должна копироваться в публичный webroot**.

## Проверка из сохранённого архива

```bash
python3 scripts/verify_release.py --root .
python3 scripts/site_publication_review.py
python3 scripts/build_site_gallery.py --check
python3 -m unittest discover -s tests -p 'test_r57_site_visual_publication.py' -q
bash tests/run.sh
```

Проверка на настоящем Nginx-порту, DNS/IPv4/IPv6, SNI, HTTP/2, TLS-сертификате и внешней сети **не выполнялась**. В итоговом внешнем отчёте r57 фиксируются результаты полного набора после чистой распаковки ZIP; встроенный этот документ не заявляет непроверенные результаты тестов.

## Сохранность и эксплуатация

`install.sh`, способы авторизации SSH (пароль-only, без SSH-ключей), Linux firewall/UFW/nftables, Docker, Xray/Remnawave и сетевые маршруты изменениями r57 не затронуты. Ничего не установлено на VPS. Публичные сайты не размещались, изменения доменов, DNS, ASN, сертификатов или Cloudflare не проводились. Этот этап улучшает внешний вид, **не подтверждает незаметность сетевого транспорта**.

Перед последующей публикацией: отдельная staging VPS, проверенный снимок/резервная копия и канал восстановления через консоль хостера; тест HTTP 200/404, корректных canonical и TLS, внешних локальных ресурсов, адаптивных страниц, логов Nginx и отката. Техническая автоматизация не заменяет независимую визуальную и редакторскую приёмку всех 120 тем. Production остаётся заблокирован до этапа 5.
