Четыре темы для самостоятельной работы

Начните с материала, который ближе к вашей задаче. Каждый пункт ведёт к подробной заметке и практическому упражнению.

  1. Организация полок

    Составьте схему небольшой полки с подписями разделов и местами для возврата книг. Проверьте, чтобы крупные тома стояли устойчиво и были доступны читателю.

  2. Понятная карточка

    Сверстайте карточку книги с автором, названием, годом и условным шифром хранения. Не придумывайте реальный инвентарный номер отсутствующего экземпляра.

  3. Тихая зона

    Нарисуйте маршрут посетителя от входа к месту чтения с учётом шума, прохода и достаточного света. Не путайте тишину с недоступностью пространства.

  4. Книги для всех

    Составьте список способов сделать материалы удобнее для разных читателей: крупный шрифт, ясные знаки и доступный проход. Проверяйте решения с пользователями.

Метод и границы материалов

Ниже приведён пример самостоятельной работы по теме издания; он не является отчётом о проведённом исследовании.

Каталог общественной библиотеки полезен, только если описание книги не путают с её реальной доступностью для выдачи.

Постройте алфавитный список и проверьте одинаковую запись авторов; не придумывайте статус «доступно» для чужой библиотеки.

Не публикуйте личные данные читателей и не обещайте фактическую выдачу книг, если такой услуги нет.
