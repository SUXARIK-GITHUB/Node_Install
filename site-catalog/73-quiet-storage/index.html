How to use these guides

  1. Backup rotation

    Backup rotation should include the files, configuration and a documented restore process. Keep at least one copy beyond the failure domain of the primary host.

  2. Cold storage

    Cold storage may be slow to access, so retrieval time belongs in recovery planning. Confirm that the media and decryption method remain available.

  3. Recovery points

    Recovery points define how much recent work could be lost. Match the interval to the importance of the data and test a representative restore.

  4. Hash verification

    A hash comparison detects byte changes between copies. It does not replace opening the recovered file or validating a restored database.

Start here: A cold-storage inventory that can be restored

An offline copy is only useful if you can identify its contents and read it after a device fails. This exercise uses disposable sample files.

  1. Create a small directory of test documents and record file names, sizes, checksums and the intended destination medium.

  2. Copy the directory to a disconnected device and verify the checksum list from the copy rather than trusting the transfer dialog.

What to notice: Inventory: Names, sizes and expected hashes are recorded.; Media: Copy is independently accessible.; Restore: Files are usable at a new location.
