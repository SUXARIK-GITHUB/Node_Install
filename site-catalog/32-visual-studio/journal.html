Color relationships

Pair a quiet neutral with one vivid color before adding more accents.

A restrained palette begins with relationships, not a fashionable hex value. Compare one saturated accent against several neutrals in the context of actual text.

Make a swatch board with one dominant hue, one supporting tone and a neutral area. Compare the same relationship on paper and a bright screen.

02 / Design

A useful grid

A working grid explains alignment without forcing every element into a box.

A grid explains alignment but should not turn every block into the same rectangle. Mark the repeating baseline and deliberately choose where to interrupt it.

Lay out six unrelated objects on a grid, then change only the spacing and alignment. Note which grouping becomes easier to read without altering the content.

03 / Design

Prototype studies

Compare paper and screen prototypes before polishing minor details.

Paper prototypes expose scale and hand interaction that a polished screen mockup can hide. Test the rough version before adjusting tiny visual details.

Cut a small paper prototype of one everyday object, photograph it from two viewpoints and record the practical issue each view reveals.

04 / Design

Small exhibitions

An exhibition needs pauses between objects as much as objects themselves.

A small exhibition needs a clear viewing sequence and places to pause. Observe whether the first object helps a visitor read the ones that follow.

Plan a miniature display around three objects with a clear entry point and enough breathing room. Label material and scale instead of inventing an exhibition history.

What to look for: A three-frame composition study

A visual grid is useful when it reveals relationships rather than forcing every object into the same frame. Photograph one ordinary item at three distances, then note what the viewer learns from context and what disappears in close-up. Treat these as composition studies, not proof that a layout outperforms another without reader testing.

Field guide

A three-frame composition study

A visual series is easier to evaluate when only the framing changes. This exercise uses one ordinary object and avoids invented campaigns or client work.

Method

  1. Place one object against a neutral background and make a wide frame that clearly shows its surroundings and scale.
  2. Create a medium and a close frame without changing the light. Record what information disappears when the object fills more of the picture.
  3. Arrange the frames in a row and ask which communicates context, material and detail; note that preference is not a measured performance result.
