Request validation

Define required fields, types, length boundaries and error responses before building a request handler. Distinguish malformed input from an unavailable dependency.

02

Idempotent operations

Retries are routine on unstable networks. An idempotency key and explicit operation state help clients avoid accidentally repeating a change.

03

Versioning contracts

Backward compatibility is easiest to keep when changes are additive and errors remain machine-readable. Record supported versions alongside examples.

04

Observability

Measure the request path without exposing tokens, cookies, passwords or personal data in the resulting logs.
