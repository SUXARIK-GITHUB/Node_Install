Questions

Answers on a readable backup, restoration day and related reading from Cold Archive.

A readable backup: Can an old backup still be read?

A backup is useful only when its format and contents remain readable.

Restoration day: What makes a restoration rehearsal useful?

Choose a small but representative set of files and restore them into an empty directory. A successful job log cannot tell you whether permissions or links survived extraction.

Checksums in practice: How can a checksum comparison reveal changed data?

Hash a deliberately created example file, copy it and compare the recorded digest. Then change one character to illustrate why the checksum is only an integrity signal.

What should I check in this material: Archive checksum?

Detects changed bytes during storage and transfer. Example: Prepare a small test set: a normal document, a directory of nested files and a name with non-ASCII characters. Record archive format, approximate size, checksum and the process for locating any encryption key.

What should I check in this material: Extraction test?

Checks that the format is readable and directories survive. Example: Restore to a separate empty directory, not onto the originals. Compare file contents, names and permissions. For a database dump, additionally load a disposable database and query a small representative sample.

What should I check in this material: Application test?

Verifies that restored information is useful, not just present. Example: Assume the original computer no longer exists. List the software, keys, access rights and instructions required to recover the files. A plan that depends on one unavailable device is incomplete.

What are the limits of this exercise?

Do not use production secrets or a live database for this exercise. A matching checksum does not prove that a system or its permissions can be restored.
