# 🚀 Node Install — Remnawave Node

> **Одна команда → 3 значения → автоматическая установка → reboot.**

Скрипт подготавливает чистую VPS под **Remnawave Node**: Docker, RemnaNode, Nginx + Let's Encrypt, локальный Selfsteal, UFW, Fail2ban, IPv4-only, BBR + fq и автоматические проверки.

## ⚡ Установка

Запускайте на сервере **от root**:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/SUXARIK-GITHUB/Node_Install/main/install.sh)
```

Если вошли обычным пользователем:

```bash
sudo -i
```

После запуска нужно указать только:

```text
[1/3] SECRET_KEY ноды (скрытый ввод)
[2/3] Публичный IPv4 основного сервера (панели)
[3/3] Домен ноды
```

После этого скрипт работает сам. `SECRET_KEY` в терминале не отображается.

## 📌 Что подготовить

- **Чистую VPS/VM**: Ubuntu 22.04/24.04 или Debian 12/13, systemd + GRUB.
- Минимум **900 MiB RAM** и **6 GiB** свободного места.
- Домен с **A-записью на IPv4 ноды**.
- У домена не должно быть **AAAA** и CDN/Proxy перед нодой.
- Во внешнем firewall хостера должны быть доступны **TCP/80**, **TCP/443** и ваш SSH-порт.
- **TCP/2222** должен быть доступен только с IPv4 основного сервера Remnawave.

> 💡 IPv4 основного сервера — это адрес, **с которого backend панели подключается к ноде**. Это не IP ноды и не IP Cloudflare.

## 🧩 Remnawave Panel

Скрипт устанавливает **сервер ноды**, но не управляет объектами панели через API.

Если Node уже создан в Remnawave и `SECRET_KEY` взят именно от него, проверьте в панели:

- IPv4 ноды;
- **Node Port: `2222`**;
- назначенный **Config Profile / Inbound**;
- Host для нужного домена и порта `443`.

## 🔎 Проверка после reboot

```bash
vkarmani-node-check
```

Полезный лог:

```bash
tail -n 120 /var/log/vkarmani-node-postboot.log
```

Если вывод содержит `VPN_STATUS=WAITING_FOR_PANEL_PROFILE`, серверная часть поднята, но панели ещё нужно передать/назначить рабочий профиль.

## 🔁 Повторный запуск

Ту же команду можно выполнить ещё раз. Уже сохранённые домен, IPv4 панели и `SECRET_KEY` повторно не спрашиваются.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/SUXARIK-GITHUB/Node_Install/main/install.sh)
```

## 🔐 Безопасность

Не публикуйте `SECRET_KEY`, приватные REALITY-ключи, сертификаты и полный `docker inspect`.

Короткие правила: **[SECURITY.md](SECURITY.md)**.
