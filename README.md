# 🚀 Node Install — Remnawave Node

> **Одна команда → 3 значения → IPv4 ноды определяется автоматически → установка → reboot.**

Установщик подготавливает чистую VPS под **Remnawave Node**: Docker, RemnaNode, Nginx + Let's Encrypt, локальный Selfsteal, UFW, Fail2ban, IPv4-only, BBR + fq и проверки после загрузки.

## ⚡ Установка

Запускайте на сервере **от root**:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/SUXARIK-GITHUB/Node_Install/main/install.sh)
```

Если вошли обычным пользователем:

```bash
sudo -i
```

Установщик спросит только:

```text
[1/3] SECRET_KEY ноды (скрытый ввод)
[2/3] Публичный IPv4 основного сервера (панели)
[3/3] Домен ноды
```

`SECRET_KEY` не отображается в терминале. **IPv4 самой ноды вводить не нужно** — он определяется автоматически. После этого дополнительных вопросов нет.

## 🌐 Как выбирается IPv4 ноды

IP вводить **не нужно**.

Скрипт:

1. Находит все публичные IPv4, реально назначенные интерфейсам VPS.
2. Проверяет A-запись введённого домена через публичные DNS.
3. Выбирает тот локальный IPv4, на который указывает домен.
4. Если у VPS два или больше IPv4 — выбирается именно совпавший с DNS адрес.
5. Если DNS ещё обновляется — установщик ждёт до 20 минут и продолжает сам.

Пример:

```text
VPS:  2.26.92.180
      13.143.195.17

DNS:  node.example.com -> 13.143.195.17

Выбрано автоматически: 13.143.195.17
```

Скрипт **не угадывает IP по default route**. Если DNS не указывает ни на один публичный адрес этой VPS, установка остановится без изменения рабочей конфигурации.

> ❗ У домена должна быть одна A-запись на нужный IPv4 ноды. AAAA и CDN/Proxy перед нодой должны быть отключены.

## 📌 Что подготовить

- 🖥️ Чистую VPS/VM: Ubuntu 22.04/24.04 или Debian 12/13, systemd + GRUB.
- 💾 Минимум **900 MiB RAM** и **6 GiB** свободного места.
- 🌍 Домен с A-записью на один из публичных IPv4 этой VPS.
- 🚫 Без AAAA и без CDN/Proxy перед нодой.
- 🔓 Во внешнем firewall хостера: SSH, TCP/80 и TCP/443.

## 🔒 IPv4 основной панели

IPv4 **панели** и IPv4 **ноды** — это разные адреса.

IPv4 панели вводится вторым значением при установке и нужен только для ограничения доступа к управляющему порту RemnaNode:

```text
TCP/2222 ← разрешён только с введённого IPv4 панели
```

IPv4 самой ноды при этом **не спрашивается**: скрипт выбирает его автоматически по A-записи домена и локальным интерфейсам VPS.

## 🧩 Remnawave Panel

Скрипт устанавливает сервер ноды, но не создаёт объекты в панели через API.

В Remnawave должны быть правильно настроены:

- Node с выбранным IPv4 ноды;
- **Node Port: `2222`**;
- Config Profile / Inbound;
- Host с доменом ноды и портом `443`.

После установки параметры сохраняются здесь:

```text
/etc/vkarmani-node/PANEL-SETUP.txt
/etc/vkarmani-node/profile.json
```

## 🔎 Проверка после reboot

```bash
vkarmani-node-check
```

Лог проверки:

```bash
tail -n 120 /var/log/vkarmani-node-postboot.log
```

## 🔁 Повторный запуск

Можно выполнить ту же команду повторно. Сохранённые `SECRET_KEY`, IPv4 панели, домен и выбранный IPv4 ноды повторно не спрашиваются и не угадываются заново.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/SUXARIK-GITHUB/Node_Install/main/install.sh)
```

## 🔐 Безопасность

Не публикуйте `SECRET_KEY`, приватные REALITY-ключи, сертификаты и полный `docker inspect`.
