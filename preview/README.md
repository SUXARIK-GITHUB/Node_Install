# Предпросмотр

Откройте `index.html` в браузере. Это пример с доменом из журнала пользователя, а не файл, развёрнутый на VPS. Новая установка генерирует подпись/акцент из собственного домена. Не копируйте вручную только index на рабочую ноду: используйте проверяемый `--update-cover`, который сначала публикует CSS/SVG и сохраняет backup.
