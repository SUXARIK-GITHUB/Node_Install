# 🔐 Безопасность

Установщик работает от **root**, поэтому запускайте его только на своей VPS и только из этого репозитория.

## ❌ Что нельзя публиковать

Никогда не добавляйте в GitHub или Issue:

- `SECRET_KEY` ноды;
- `/etc/vkarmani-node/remnanode.env`;
- приватные REALITY-ключи и `reality.json` / `profile.json` с private key;
- приватные ключи Let's Encrypt;
- полный вывод `docker inspect`;
- логи, если вы не проверили их на наличие секретов.

## 🚨 Если секрет попал в GitHub

1. Сразу замените/перевыпустите соответствующий ключ в Remnawave.
2. Убедитесь, что старый ключ больше не работает.
3. Удалите секрет из репозитория и его истории.

Просто удалить строку новым коммитом недостаточно — значение может остаться в истории Git.

## 🛡️ Сеть

- `TCP/2222` открывается только для IPv4 основного сервера Remnawave.
- `TCP/80` используется для Let's Encrypt.
- `TCP/443` используется клиентами VPN.
- Не открывайте `2222` всему интернету для обхода проблем подключения.

## 🐞 Сообщение об ошибке

Можно приложить вывод установки или `/var/log/vkarmani-node-install.log`, но **сначала проверьте файл и удалите любые секретные данные**.
