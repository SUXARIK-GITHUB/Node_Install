# 🔐 Безопасность

Скрипт выполняется от **root**. Запускайте его только на своей VPS и только из доверенного репозитория.

## ❌ Не публикуйте

- `SECRET_KEY` ноды;
- `/etc/vkarmani-node/remnanode.env`;
- `/etc/vkarmani-node/profile.json` и `reality.json`;
- приватные ключи Let's Encrypt;
- полный `docker inspect`;
- необработанные логи, если в них могут быть секреты.

## 🌐 Порты

- `22/tcp` или ваш текущий SSH-порт — администрирование;
- `80/tcp` — Let's Encrypt HTTP-01;
- `443/tcp` — VLESS + RAW + REALITY;
- `2222/tcp` — Node API, только от IPv4 панели Remnawave.

Nginx Selfsteal работает через **Unix socket `/dev/shm/nginx.sock`** и не требует отдельного публичного TLS-порта.

Если у VPS-провайдера есть внешний Firewall / Security Group, правило для `2222/tcp` необходимо создать и там. UFW внутри VPS не может изменить правила провайдера.

## 🚨 Если SECRET_KEY утёк

1. Перевыпустите/замените ключ ноды в Remnawave.
2. Убедитесь, что старый ключ больше не используется.
3. Удалите секрет из GitHub и истории Git.

Просто удалить строку новым коммитом недостаточно — старое значение останется в истории.

## 🐞 Логи для диагностики

Безопасные базовые команды:

```bash
vkarmani-node-check
systemctl status vkarmani-node --no-pager
```

Перед публикацией любых дополнительных логов проверьте, что в них нет `SECRET_KEY`, токенов или приватных ключей.
